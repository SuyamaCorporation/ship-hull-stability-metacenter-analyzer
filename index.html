Formula Reference

KB = T / 2 (vertical centre of buoyancy for box hull)

BM = I / V = (L·B³/12) / (L·B·T·Cb) = B² / (12·T) for box hull (Cb=1)

BM (general) = B² / (12·T·Cb) (approximate for non-box hulls)

KM = KB + BM

GM = KM − VCG

GZ ≈ GM · sin θ (linearised, small-angle approximation)

Displacement ∇ = L · B · T · Cb (m³)

Stability criteria: GM > 0.15 m = Stable, 0 < GM ≤ 0.15 m = Marginal, GM ≤ 0 = Unstable
